## Installation

```shell
git clone https://github.com/jeremy-code/exifi.git
cd exifi
corepack enable
pnpm install
```

## Usage

```shell
# Run the development server locally
pnpm dev

# Lint and format code with Oxlint and Oxfmt
pnpm lint
pnpm format

# Build
pnpm build
```
