# @exifi/client

[![Netlify Status](https://api.netlify.com/api/v1/badges/027f759e-5e19-4417-9311-394ce8cd4bbc/deploy-status)](https://app.netlify.com/projects/exifi/deploys)

React, TanStack Start, Vite client hosted on Netlify at [exifi.io](https://exifi.io). Supports offline use via PWA with Serwist.

## Internationalization

The following languges are currently supported.

- English (<https://exifi.io>)
- German/Deutsch (<https://exifi.io/de>)
- Spanish/Español (<https://exifi.io/es>)
- French/Français (<https://exifi.io/fr>)
- Japanese/日本語 (<https://exifi.io/ja>)

If you would like to add support for another language, consider [opening a new issue on GitHub](https://github.com/jeremy-code/exifi/issues/new/choose). You can also assist in translations through <https://fink.inlang.com/> by inputting the URL `github.com/jeremy-code/exifi`.
