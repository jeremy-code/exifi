# @exifi/api

[![Netlify Status](https://api.netlify.com/api/v1/badges/f805d239-bc98-482c-8ef2-20f81ee47bc3/deploy-status)](https://app.netlify.com/projects/exifi-api/deploys)

Hono API server hosted on Netlify at [api.exifi.io](https://api.exifi.io). This API is not used in the exifi client app ([apps/client](../client) or [exifi.io](https://exifi.io)) and is a standalone REST API that can be used to query Exif data regarding an image.
